Privacy Policy — SDR Spectrum Analyzer

Last Updated: September 2026
Application: SDR Spectrum Analyzer
Publisher: Mattino 507 Software

1. Overview

SDR Spectrum Analyzer is a Windows desktop application published by Mattino 507 Software.

2. Information Collection and Use

SDR Spectrum Analyzer does not collect, transmit, sell, or share personal information. The application:

  • Does not require a user account or login credentials.
  • Does not contain advertising.
  • Does not use analytics, telemetry, or cloud-based tracking services.

3. Local Data Processing

Radio-frequency (RF) sample data and measurement results are processed strictly locally on the user's computer. SDR Spectrum Analyzer does not transmit RF measurement data or usage statistics to Mattino 507 Software or to any third-party online services.

4. Hardware Interaction

The application may access locally connected compatible USB software-defined radio (SDR) hardware in order to perform its intended spectrum-analysis functions. Hardware identification and operational data required by the application are processed entirely locally.

5. Files Created and Stored by User

If the user exports measurement data or other files, those files are saved in file system locations directly selected by the user and remain entirely under the user's control.

6. Third-Party Components

SDR Spectrum Analyzer includes third-party open-source or runtime software components required for local operation. These components are used to support local application functionality. SDR Spectrum Analyzer does not use these components to transmit personal information to Mattino 507 Software or third-party online services.

7. Changes to This Privacy Policy

We may update our Privacy Policy from time to time if the application's functionality or data-handling practices change. Any updates will be posted with a revised "Last Updated" date at the top of this policy.

8. Contact Information

Questions or comments about this Privacy Policy may be directed to the support contact provided on the SDR Spectrum Analyzer page in the Microsoft Store listing.
