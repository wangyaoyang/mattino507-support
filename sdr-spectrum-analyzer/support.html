SDR Spectrum Analyzer — Support

Application: SDR Spectrum Analyzer
Publisher: Mattino 507 Software

This page provides support information for SDR Spectrum Analyzer, a Windows desktop application for RF spectrum analysis using compatible USB software-defined radio (SDR) hardware.

Supported Environment

SDR Spectrum Analyzer is designed for supported Windows systems and compatible USB SDR hardware.

Hardware compatibility may depend on the SDR device, tuner, USB configuration, Windows driver configuration, and operating-system environment.

Before Requesting Support

If you encounter a problem, please check the following:

  • Confirm that the SDR device is physically connected to the computer.
  • Restart SDR Spectrum Analyzer and reconnect the device.
  • Confirm that Windows recognizes the USB device.
  • Make sure another SDR application is not currently using the same device.
  • Restart Windows if the USB device has stopped responding.

Information to Include in a Support Request

Providing the following information will help us investigate the problem:

  • SDR Spectrum Analyzer version.
  • Windows version.
  • SDR hardware model and tuner type, if known.
  • A short description of the problem and the steps that reproduce it.
  • The exact error message displayed by the application, if any.
  • A screenshot, when useful.

Please do not include passwords, account credentials, product keys, or other sensitive personal information in support requests.

Measurement Questions

SDR Spectrum Analyzer displays RF measurements based on data obtained from the connected SDR hardware. Results can be affected by hardware characteristics, gain, frequency accuracy, sampling configuration, connected RF components, and the measurement environment.

Unless explicitly stated otherwise, displayed power values are relative measurements such as dBFS and should not be interpreted as calibrated absolute RF power measurements.
