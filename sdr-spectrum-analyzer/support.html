SDR Spectrum Analyzer — Support

Application: SDR Spectrum Analyzer
Publisher: Mattino 507 Software

This page provides support information for SDR Spectrum Analyzer, a Windows desktop application for RF spectrum analysis using supported USB software-defined radio (SDR) receivers. The complete instructions are in the User Guide; the guide for the installed version is also available in the application under Help > User Guide.

Supported Environment

  • Windows: Windows 10 version 2004 or later.
  • RTL-SDR: tested RTL2838-based USB hardware (VID:PID 0BDA:2838) with an R820T-series tuner, with a working Microsoft WinUSB driver on the device's Interface 0. Only this tested path is claimed; other RTL-SDR devices, clones and tuner families are not.
  • SDRplay RSP1B: the SDRplay API must be installed from SDRplay before you connect the RSP1B. The application uses the installed API; it does not include or install it.

Installing SDR Spectrum Analyzer does not install, download, update or replace any receiver driver or the SDRplay API. Hardware behaviour may also depend on the USB configuration and the operating-system environment.

Before Requesting Support

If you encounter a problem, please check the following:

  • Confirm that the receiver is physically connected to the computer.
  • On the Control Panel, press Device, then Refresh, select the receiver and connect again.
  • For an RSP1B that is not listed, check that the SDRplay API is installed; install or repair it from SDRplay, then refresh.
  • For an RTL-SDR, the readiness message tells you whether Interface 0 is bound to WinUSB. The application does not change a driver.
  • Make sure no other application is using the same receiver.
  • If a connection looks wrong, select Device > Check Connection in the menu bar. It tests the open device again without changing the connection.
  • Restart SDR Spectrum Analyzer, and restart Windows if the USB device has stopped responding.

The User Guide sections Recovering from Common Errors and Troubleshooting reference explain each message the application shows.

Information to Include in a Support Request

Providing the following information will help us investigate the problem:

  • SDR Spectrum Analyzer version (Help > About).
  • Windows version.
  • Receiver model (RTL-SDR or RSP1B) and, for an RTL-SDR, the tuner type if known.
  • Edition: Free Version or Full Version.
  • A short description of the problem and the steps that reproduce it.
  • The exact error message displayed by the application, if any. File > Save Diagnostic Log... in the menu bar saves the diagnostic messages to a file you can attach.
  • A screenshot, when useful. On the Control Panel, press File, then Export Screenshot..., to save the spectrum view.

Please do not include passwords, account credentials, product keys, or other sensitive personal information in support requests.

Measurement Questions

SDR Spectrum Analyzer displays RF measurements based on data obtained from the connected SDR hardware. Results can be affected by hardware characteristics, gain, frequency accuracy, sampling configuration, connected RF components, and the measurement environment.

The level scale depends on the receiver and on calibration:

Unit When it is shown
dBFS RTL-SDR device data: relative to the digital full scale.
Rel.dB RSP1B device data: a relative level referred to the receiver input. It is neither dBFS nor dBm.
Raw Rel.dB RSP1B, when no trustworthy system gain is available, or at 8 MS/s with a system gain below 15 dB. It is not comparable with Rel.dB.
dBm Only when a matching calibration applies. It is derived from your own reference measurement and is valid only for the setup it was made with.

SDR Spectrum Analyzer is not a calibrated laboratory spectrum analyser or a precision power meter, and it does not guarantee absolute dBm accuracy.

Channel Power reads in Rel.dB or dBFS although I calibrated

A channel-power calibration applies only to the exact settings it was made with. An RSP1B channel-power calibration applies only when all 9 settings match (mode, centre frequency, channel bandwidth, sample rate, IF bandwidth, Gain Reduction, LNA state, FFT points and window); Channel Power then reads in dBm (ch. cal.) while the trace stays in Rel.dB. Restore those settings (a saved configuration file is the easiest way) or recalibrate, and check that Disable Calibration under Cal is off.

Channel Power of a narrowband signal in RSP1B Sweep mode

In the tested configuration (Sweep mode, 496 MHz, span 30 MHz, channel bandwidth 20 MHz, 8 MS/s, IF 8 MHz), the Channel Power reading of a CW signal was observed to depend on its position in the channel by about 1 dB compared with a broadband OFDM reference. This is an observation from that configuration, not a guaranteed maximum error. Where accuracy matters, check the result against a reference instrument with a signal of the kind you measure.

What do the marks on an RSP1B trace mean?

Possible internal spur interference marks a peak on a frequency where the RSP1B can produce internal lines, and Suspected IQ Image marks a peak that may be a mirror image of a stronger signal. Both marks are hints for the display only; they are not measurements, and the absence of a mark does not mean that no such line is present.

Full Version Purchase and Restore

SDR Spectrum Analyzer is free to download. The Full Version is an optional one-time purchase through the Microsoft Store, with no subscription. The Free Version and the Full Version are the same installed application: which features it enables follows the Microsoft Store entitlement held by the Microsoft account that is signed in to the Store on that computer. Pricing is shown by the Microsoft Store for your region; before the Microsoft Store opens, the application shows that price and asks you to confirm.

The command Help > Purchase or Restore Full Version... shows the current state:

  • Purchase or Restore Full Version... in the Free Version;
  • Checking Full Version... while the licence is being checked;
  • Purchasing Full Version... while a Microsoft Store purchase is open;
  • Retry Microsoft Store... if the Microsoft Store could not be reached; select it to check the licence again;
  • Full Version, not selectable, when the Full Version is active.

There is no command that switches between the editions by hand. The edition follows the Microsoft Store licence check, which runs at startup, after every purchase or restore in the Microsoft Store, and when Windows reports a licence change. If the Microsoft Store cannot be reached, the application stays in the Free Version until a later check succeeds. The User Guide section Free and Full Versions explains what changes when the edition changes.

I already purchased Full Version. Why does another PC show Free mode?

A Full Version licence belongs to your Microsoft account, not to one computer. On a newly set up PC, Windows may not have made the licence available locally yet. You do not need to buy it again.

  1. Sign in to the Microsoft Store on that PC with the Microsoft account that owns the purchase.
  2. Install and start SDR Spectrum Analyzer from the Microsoft Store.
  3. In the application, choose Help > Purchase or Restore Full Version... If the command reads Retry Microsoft Store..., select it first; it checks the licence again.
  4. The Microsoft Store may report that the account already owns the Full Version. If it does, you do not need to purchase it again.
  5. Return to the application. It checks the Full Version licence again as soon as the Store interaction ends.
  6. If the application still shows Free mode, close and restart it so that it can check the Store entitlement again during startup.

Neither the Store interaction nor a restart forces Windows to make the licence available locally. Each one only gives the application another opportunity to read the licence the PC currently holds for the signed-in account.

If Free mode continues, no Full Version purchase was found for the Microsoft Store account currently signed in on that PC. That describes what this PC reported for that account at that moment; it is not a statement about whether the purchase exists. Check that you are signed in with the account that made the purchase.

我已经购买了完整版，为什么另一台电脑仍显示 Free 模式？

完整版授权归属于您的 Microsoft 账户，而不是某一台电脑。在刚刚设置好的电脑上， Windows 可能尚未将该授权在本机就绪。您不需要再次购买。

  1. 在该电脑上使用拥有这笔购买的 Microsoft 账户登录 Microsoft Store。
  2. 从 Microsoft Store 安装并启动 SDR Spectrum Analyzer。
  3. 在应用中选择帮助 > 购买或恢复完整版...。如果该命令显示为重试 Microsoft Store...，请先选择它；它会再次检查授权。
  4. Microsoft Store 可能会提示该账户已经拥有完整版。如果出现此提示，则无需再次购买。
  5. 返回应用。Store 交互结束后，应用会立即再次检查完整版授权。
  6. 如果应用仍显示 Free 模式，请关闭并重新启动应用，使应用在下次启动时再次检查 Store 授权。

Store 交互和重新启动都不会强制 Windows 将授权在本机就绪，它们只是让应用 多一次机会，去读取本机当前为已登录账户保存的授权。

如果仍然显示 Free 模式，说明在该电脑当前登录的 Microsoft Store 账户下未找到完整版购买记录。这只是对本机、该账户、此刻查询结果的 描述，并不说明该购买是否存在。请确认登录的是完成购买的那个账户。

应用中没有手动切换版本的命令；版本由 Microsoft Store 授权检查决定。
